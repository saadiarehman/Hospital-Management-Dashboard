# 🏥 Hospital Management Dashboard

A responsive and interactive Hospital Management Dashboard built with **React, TypeScript, Tailwind CSS, and Recharts**. This project provides a centralized interface for managing hospital operations, monitoring patient information, tracking appointments, and viewing healthcare analytics.

## 🚀 Features

### 📊 Dashboard
- Overview of hospital activities.
- KPI cards for total patients, doctors, appointments, and available beds.
- Patient admission statistics.
- Department distribution chart.
- Upcoming appointments.
- Recent activities.

### 👥 Patient Management
- View patient records in a structured table.
- Add new patients using a form.
- Search patients by name, ID, or phone number.
- Filter patients by gender and status.
- Dynamic statistics for total, admitted, discharged, and pending patients.
- Clickable statistics cards to filter patient records.

### 👨‍⚕️ Doctor Management
- View doctor information.
- Display doctor specializations and departments.
- Track doctor availability and status.

### 📅 Appointment Management
- View appointment records.
- Display patient and doctor details.
- Track appointment dates, times, and statuses.
- Search and filter appointments.

### 🏢 Department Management
- Display hospital departments.
- View department information and statistics.

### 💳 Billing Management
- View patient invoices.
- Track paid and pending payments.
- Display revenue statistics.

### 📈 Reports
- Healthcare reporting interface.
- Different report categories and date ranges.

### 🗂️ Medical Records
- Medical record management interface.

### ⚙️ Settings
- Hospital profile settings.
- Account settings.
- Notification preferences.
- System preferences.

## 🛠️ Technologies Used

- **React** – Building reusable UI components.
- **TypeScript** – Type safety and maintainable code.
- **Tailwind CSS** – Responsive styling and layout.
- **React Router** – Page navigation and routing.
- **Recharts** – Data visualization and analytics charts.
- **Lucide React** – Icons.
- **Vite** – Development and build tooling.

## ⚙️ Installation and Setup

### 1. Clone the repository

```bash
git clone https://github.com/saadiarehman/Hospital-Management-Dashboard.git
```

### 2. Navigate to the project directory

```bash
cd Hospital-Management-Dashboard
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the development server

```bash
npm run dev
```

### 5. Open in your browser

Visit the local URL displayed in your terminal.
